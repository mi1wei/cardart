- 深色模式：`:root[data-theme=dark]` 一套令牌（底 `#121417`、面板 `#1a1d21`、主色 `#7fc0e0` 配深色字）。顶栏新增「☀ / ☾ / 自动」三段（手机折叠为单个图标按钮循环切换）；默认「自动」跟随 `prefers-color-scheme`；选择存 `localStorage`，每台设备各自记住；首屏前内联脚本设置 `data-theme` 防闪烁。3D 场景背景随主题变暗；看大图始终深色。
- 细节修复：
  - 看大图品牌字中英文都显示 Folio。
  - 面包屑末项为当前相册名，无悬空 `/`。
  - 相册卡：数量带单位（「9 张」「5 张 · 2 段视频」）；空相册显示「还没有照片」并用 `--hover` 色占位卡。（日期范围在 S3 加。）
  - 「选择」按钮加 ☑ 图标；相册页新增「⋯」菜单，S1 先放「重命名 / 删除相册」，「导出 PDF」在 S7 加入。
  - 删除「完整显示 · 不裁切」等小提示。
  - 首页「最近的相册」跳过空相册。（改为按 `updatedAt` 的「最近更新」在 S3；功能卡 3/4 换文案随对应功能上线时更新。）
- 骨架屏：相册墙 / 相册网格首次加载显示 `--hover` 色占位块，数据到后替换。

## 4. 看大图（S2）

- 始终深色底 `#0d0f11`，去掉灰框，照片按「适应」最大化。
- 顶栏：`‹ 相册名`、`n / N`，右侧图标按钮：ⓘ 详情、☆ 设为封面、⤓ 下载原图、🗑 删除。
- 详情：右上浮层卡（宽 290px），内容同现有详情面板（文件名、格式/尺寸/大小、备注编辑、拍摄、文件分组）；默认关闭，按 ⓘ 或 `I` 切换，状态每台设备记住。
- 胶片条：底部缩略图条，当前项白色描边，视频带 ▶ 角标；点击跳转；2 秒无操作淡出，鼠标移动/触摸即恢复。
- 缩放：滚轮 / 触控板捏合 / 双指 / 双击；`+ − 0` 键；底部缩放条（− 适应 + 1:1）。放大后可拖动平移，右下角小地图显示可视区。放大状态下左右滑动不翻页。视频不缩放。
- 手机：左右滑翻页，下滑关闭，上滑打开底部详情面板（含备注、设为封面、删除）；顶栏 ⓘ ⤓ ⋯。
- 快捷键：← → 翻页、`+ − 0` 缩放、`I` 详情、空格播放/暂停视频、Esc 依次退出缩放 → 关详情 → 关闭。
- 删除走最近删除（S4），出现撤销条。

## 5. 排序与搜索（S3）

服务端数据：
- 照片记录新增 `addedAt`（导入时 ISO 时间）。旧照片无此字段时按数组顺序视为更早。
- 相册新增 `updatedAt`（任何内容变更时更新；旧相册缺省为 `createdAt`）和 `sort`：`'taken' | 'added' | 'manual'`（缺省 `'manual'`，保持现有顺序不变）。
- `taken` 排序用 `metadata.takenAt.local`；无拍摄时间的排最后，再按 `addedAt`。旧照片缺 metadata 的，打开相册库后后台逐个补读，补完后排序自动更新。
- `album.photos` 仍存手动顺序；`sort ≠ manual` 时服务端返回排好序的列表。拖动排序只在 `manual` 下可用，若在其他模式下拖动，先提示「切换为手动排序？」。
- 相册列表返回 `updatedAt`、`dateRange: { from, to } | null`。

界面：
- 相册卡显示「数量 · 拍摄月份范围」；相册页标题下显示拍摄日期范围（无拍摄时间时不显示）。
- 首页「最近的相册」改名「最近更新」，按 `updatedAt` 倒序；功能卡 3 换为「按拍摄时间」。
- 相册页：排序下拉（拍摄时间 / 上传时间 / 手动），存到相册（`PATCH sort`）。
- 相册墙：排序下拉（最近更新 / 创建时间 / 名称），每台设备记住；「最近删除」固定最后。
- 搜索：相册墙搜相册名；相册页 ⌕ 展开搜索框，匹配文件名与备注（不区分大小写、中英文子串）；客户端过滤，无结果显示空状态 + 清除按钮。搜索中禁用拖动排序。

## 6. 最近删除 + 撤销（S4）

存储：相册库内 `.trash/`：
- 删照片：文件移动到 `.trash/<entryId>/`，并写 `entry.json`（`{ id, kind: 'photos', albumId, albumTitle, deletedAt, photos: [原记录] }`），再从 `album.json` 移除。
- 删相册：整个相册目录移动到 `.trash/<entryId>/album/`，`entry.json` 记 `kind: 'album'`。
- 顺序保证崩溃安全：先写 entry 与移动文件，最后改 `album.json`；启动时清理不完整条目。
- 30 天后清除：启动时与每 6 小时检查一次 `deletedAt`。
- 恢复：照片放回原相册末尾（`manual` 时）；原相册不存在时先恢复相册（若相册也在回收站）或新建同名相册。ID 冲突时重新分配照片 ID。
- 回收站内容不计入相册数量、统计、搜索。

API：`GET /api/trash`、`POST /api/trash/restore { ids }`、`POST /api/trash/purge { ids | all }`；现有删除接口改为移入回收站并返回 `trashId`。

界面：
- 撤销条：右下（手机底部）「已移到「最近删除」· N 张照片 撤销」，8 秒；撤销 = restore 该条目。
- 相册墙最后一张虚线卡「最近删除 · N 项 · 30 天后清除」，为空时隐藏。
- 最近删除页（路由 `#/trash`）：说明横幅；分「相册」「照片和视频」两组；每项显示来源相册与剩余天数；选择后底部悬浮条「↺ 恢复」「✕ 彻底删除」；右上「全部彻底删除」。彻底删除二次确认。点单张进只读看大图（顶栏只有恢复 / 彻底删除）。
- 首页功能卡 4 换为「误删可找回」。
- README「删除」一节改写。

## 7. 批量操作（S5）

- 选择模式：顶部只留「全选」「完成」；底部悬浮深色条「已选 N · ↗ 移动到 · ⧉ 复制到 · ⤓ 下载 · 🗑 删除 · ✕」，替换上传/3D 悬浮按钮。
- 移动到 / 复制到：弹出相册选择列表（可「＋ 新建相册」）；复制在服务端复制原文件与缓存并分配新 ID；重复（sha256 已存在于目标相册）跳过并汇总提示。
- 下载：1 项直接下载原文件；多项由服务端流式打包 ZIP（不压缩），文件名重名加序号。需把 `yazl` 从 devDependencies 移到 dependencies 并更新第三方声明。
- 键盘（桌面）：`⌘/Ctrl+A` 全选、Shift+点击连选、`Delete/Backspace` 删除、Esc 退出。
- 手机：长按照片进入选择；悬浮条为「↗ 移动 · ⤓ · 🗑」，复制在「移动」菜单里。

## 8. 3D 增强（S6）

- 扉页：翻开后的第一个左页显示相册名（衬线）、分隔线、日期范围、数量；自动生成，不可编辑。
- 图注：有备注的照片下方一行斜体衬线小字，超长省略；点照片仍进看大图。
- 顶栏：`✕ 返回`、相册名、每页 N 张、⛶、`📕 合上`（图标 + 文字）。
- 底部：一组胶囊 `‹ n/N › │ ▶ 自动翻阅`。播放时原地变为 `⏸ │ 慢·中·快 │ ✕`，顶栏淡出、顶部进度线；鼠标移动或点按恢复控件。速度慢/中/快 = 每跨页 8/6/4 秒，每台设备记住。到最后一页自动合上并停止。空格 = 播放/暂停。
- 合上状态：底部「📖 打开相册」（主）+「▶ 自动翻阅」（次，从封面开始）。
- 手机竖屏：单页模式，相机对准右页，环扣在左缘，左右滑翻页、页角卷起；页码按「页」计。底部同样 `‹ n/N 页 › │ ▶`。横屏保持双页。取消「请横过手机」提示。

## 9. 导出 PDF（S7）

- 入口：相册页「⋯ → 导出 PDF」，仅电脑端。
- 对话框：左预览（封面页 + 第一跨页 + 总页数），右选项：纸张（A4 横向 / Letter 横向）、每页照片（1/2/3，默认同 3D 设置）、画质（标准 / 高）、封面页、备注作为图注。视频只放封面帧并标「视频」。
- 生成：新增打印版式页面（复用 `src/book/layout.js` 的分页），桌面版用 Electron `webContents.printToPDF` 输出并保存到「下载」；源码 / 浏览器模式退化为 `window.print()`（用户在系统对话框选「存为 PDF」）。不引入新的 PDF 依赖。
- 进度显示在「导出」按钮上，完成后 toast「已保存到 下载/xxx.pdf」并可在 Finder/资源管理器中显示。

## 10. 错误处理

- 所有新写操作沿用 `allowWrite()` 授权检查与 `data-busy` 互斥。主题切换只改 `data-theme`、不重建页面，导入中也可切换；语言切换仍在导入中禁用。
- 回收站移动失败：保持原状并 toast；不出现半删除。
- ZIP / PDF 生成中断：删除临时文件，toast 失败原因。
- 排序字段非法：服务端 400，界面回退为手动。
