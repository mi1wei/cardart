Folio bundled asset provenance

The application icon derives from src/assets/folio-mark.svg. The web,
Windows, macOS and menu-bar forms are generated by scripts/generate-icons.js.
This record does not provide a trademark clearance opinion.

The mockup's scenes.js contains original SVG stand-in scenes and explicitly
uses no external images. This establishes local repository provenance, not
an independent certification of every rendered/encoded frame's rights.
Maintainers must confirm the media rights and H.264 distribution conditions
before approving distribution.

Geist Variable is supplied by @fontsource-variable/geist 5.3.0 under OFL-1.1.
The upstream font license is retained, including public/geist-OFL.txt.
System fallback fonts are used through the OS and are not copied into Folio.

Runtime user photos, library data, received licenses and test photo fixtures
must never be included in an installer, legal bundle or public CI artifact.
The generator binds the listed asset bytes to the inventory digest so a
changed asset requires renewed review rather than inheriting old approval.

The video fixtures in tests/fixtures/videos are owned synthetic test patterns,
not user media. They are excluded from installers and legal asset bundles.
The base H.264/AAC samples were generated with the maintainer's existing
ffmpeg from lavfi testsrc2 (320x180, 12 fps, 2 seconds) and silent anullsrc
(44100 Hz stereo), using libx264/yuv420p and AAC. MOV uses the same streams;
M4V uses an MP4 muxer with the "M4V " major brand. No generator or codec
dependency is added to the application or required to run tests.

Derived fixtures can be prepared once with:
  ffmpeg -display_rotation:v:0 90 -i h264-aac.mp4 -c copy h264-rotated.mp4
  ffmpeg -f lavfi -i testsrc2=size=160x90:rate=12 -t 0.083333 -an \
    -c:v libx264 -preset veryfast -threads 2 -pix_fmt yuv420p \
    -movflags +faststart h264-tiny.mp4
  ffmpeg -f lavfi -i testsrc2=size=1920x1080:rate=12 -t 0.25 -an \
    -c:v libx264 -preset ultrafast -threads 2 -crf 32 -pix_fmt yuv420p \
    -movflags +faststart h264-large.mp4

These fixtures establish repository test provenance, not codec/patent
distribution clearance or universal playback support.
