# Folio

本地相册管理工具：照片存在自己的电脑上，在浏览器里管理，用 3D 翻阅的方式看；同一 Wi‑Fi 下手机扫码也能看、能上传。界面有中文和英文。

## 运行

源码运行需要 macOS 和 Node 24 以上；`.nvmrc` 指定开发/CI 使用的 Node 24 LTS。

```bash
npm install
npm start
```

然后打开 http://localhost:5180 ，先看到首页（介绍、翻书视频和最近更新的相册），顶栏「相册」进入相册墙；相册库为空时相册墙显示欢迎页，可以从这里新建第一本相册。

- 相册库默认在 `~/Pictures/相册库`，用 `ALBUM_LIBRARY=/你的/路径 npm start` 换位置。
- 端口默认 5180，用 `PORT=5181 npm start` 换端口。
- 开发：`npm run dev`；要让手机访问开发服务器，用 `npm run dev -- --host`。

## 语言

第一次打开时跟随浏览器语言：中文系统显示中文，其他显示英文。点顶栏右边的齿轮打开「设置」，在「语言」一行切换，每台设备各自记住。正在准备或导入照片/视频时不能切换语言或相册库，以免丢失导入队列。在电脑上，「设置」里还能看到许可证状态，点「管理…」进入许可证页。

## 外观

在「设置」的「外观」一行选浅色、深色或自动（跟随系统，默认），每台设备各自记住；导入照片时也能切换。浏览器太旧（iOS 17.4 及以下）时没有这一行，只有浅色。照片带白边（深色下为深灰边）；相册页右侧的滑块调缩略图大小（小 / 中 / 大），手机上固定大小。

## 导入

在电脑上，可以把照片、视频或整个文件夹拖进 Folio：

- 拖到相册墙（没有相册时是欢迎页）：每个文件夹新建一本相册，相册名就是文件夹名（去掉首尾空白，超过 50 字截断）；只拖了零散的照片时，先给新相册起名，取消就什么都不导入。多个文件夹依次导入，右下角显示进度，完成后弹出汇总。导入期间不能离开相册墙。
- 拖到相册页：照片加进当前相册，文件夹里的照片也一样，不新建相册。
- 欢迎页的「从文件夹导入…」一次选一个文件夹。

松手后 Folio 先读一遍拖入的文件，文件多时要等一会儿：这时显示「正在读取拖入的文件…」和已找到的数量，读完再开始导入；读取期间再拖入会提示「请等上一批读完」，不会重复导入。

子文件夹里的照片并入同一本相册。以 `.` 开头的文件和文件夹，以及 Windows 的 `desktop.ini`、`Thumbs.db` 会被忽略；其他格式的视频（如 AVI、MKV、WebM）记为「格式不支持」，其余不是照片或视频的文件跳过，两者都在汇总里计数；读不出的文件计为失败，不影响其他文件。手机上不提供文件夹导入。

## 3D 翻阅

点相册页的「3D 翻阅」打开。翻开后第一个左页是扉页：相册名、拍摄日期范围（有拍摄时间的照片才有）和数量，自动生成。有备注的照片下方显示一行图注，太长时省略，点照片看全文。顶栏的「版式」可选单张、宽松或紧凑，保存在相册内；手机上在下拉菜单里选。

底部「▶ 自动翻阅」按慢 / 中 / 快（每跨页 8 / 6 / 4 秒）自动翻页，每台设备记住速度；播放时控件几秒后淡出，移动鼠标或点一下屏幕就回来。空格键播放 / 暂停，Esc 先停止自动翻阅、再按一次关闭 3D。打开照片时自动暂停；翻到最后一页自动合上。相册合上时，「▶ 自动翻阅」从封面开始播放。

全屏和手机横竖屏时只显示相册：无操作 2.5 秒后控件开始淡出（约 3 秒完全隐藏），移动鼠标或轻点空白处就回来，2.5 秒后再淡出；在页面上滑动直接翻页，不会唤出控件，点照片仍然看大图。

手机竖着拿时一次显示一页，左右滑动或点两侧翻页，页码按页计（扉页是第 1 页）；横过来恢复双页。竖屏相册高度约占可视区域的 80%，宽度不变、上下居中留白。手机横竖屏的顶部工具栏和底部控件都悬浮覆盖相册，不为控件预留上下空白，顶部不再显示全屏图标。

## 视频

同一本相册可以混排照片与 MP4、MOV、M4V 视频，一起排序、设封面、添加备注和删除。每个视频最多 **1 GB（1,000,000,000 字节）**，不额外限制时长。

Folio 原样保存视频，不转码、不换封装，也不打包新的 ffmpeg 或编解码器。导入设备的浏览器需要能解码视频并生成 JPEG 封面；其他设备的播放能力取决于其浏览器、系统和可用解码路径，容器后缀不保证某种编码可播放。

不能播放时仍保留封面、详情、备注和原文件入口；读取失败与设备不支持会分别提示。3D 相册只显示视频封面、播放标记和时长，点击后进入原生播放器，不在书页内播放。许可证到期不会删除视频，仍可查看与备份。

## 看大图

电脑上，照片在左边的框里，右边是详情卡（文件信息、拍摄信息和备注），颜色跟随应用的浅色 / 深色外观。详情卡默认打开；点顶栏「详情」或按 `I` 开关，选择在电脑上记住，`Esc` 只是暂时收起。顶栏有返回、相册名、`n / N` 和上一张 / 下一张；卡上文件名旁边是「删除」，下方是「下载原图」（视频为「下载原视频」）和「设为相册封面」。复制、移动在相册页里做。

手机上查看器是深色全屏，底部胶片条可跳转照片和视频；无操作时自动淡出，触摸恢复。顶栏右侧是「详情」「下载原图」和「⋯」，详情从底部展开，默认关闭，选择单独记住。「⋯」里可以设为相册封面、复制或移动到其他相册（可新建相册，相同文件会跳过；移走后显示下一项，相册空了就关闭），以及删除。

照片支持滚轮、双击、双指缩放和拖动平移；底部可切换「适应」「1:1」（电脑上放大后才出现），放大时右下角小地图显示可见范围。视频使用原生播放控件，不缩放。键盘 `← / →` 翻页、`+ / − / 0` 缩放、空格播放或暂停视频；`Esc` 依次退出缩放、关闭详情、关闭查看器。编辑备注时保留正常的输入快捷键。手机左右滑翻页、下滑关闭、上滑展开底部详情。

## 排序与搜索

相册页可以按拍摄时间、添加时间或手动顺序浏览，排序保存在相册内。没有拍摄时间的内容排在最后；旧文件在后台补读拍摄信息。切换显示顺序不会覆盖已有的手动顺序，拖动前会提示切回手动。相册卡在照片数后面显示拍摄月份范围（如「8 张照片 · 2026年7月」）。日期在相册页、3D 扉页、PDF 封面和详情里写法一致，如「2026年7月12日–15日」。

相册墙按名称搜索相册，支持最近更新、创建时间、名称排序；该选择在设备上记住。相册页点放大镜搜索文件名与备注，中英文和大小写都支持；搜索不改动原始顺序，搜索期间不能拖动排序。

## 批量操作

点「选择」后可以全选或 Shift 点击连续选择，底部悬浮条支持移动、复制、下载和删除。`⌘ / Ctrl+A` 全选，`Delete / Backspace` 删除，`Esc` 退出选择；手机长按照片进入选择，移动菜单里也可以选复制。

移动或复制时选择目标相册，也可新建相册；相同文件会跳过并汇总。复制保留原文件、视频封面、拍摄信息和备注。下载一项直接获取原文件，多项下载为不压缩的 ZIP，重名文件自动编号。

## 右键菜单与快捷键

电脑上右键照片可打开、在 3D 中查看、设为封面、编辑备注、复制、移动、下载或删除；右键已选照片时，复制、移动、下载和删除作用于整个选择，右键未选照片只操作那一项。相册卡支持打开、3D 翻阅、重命名、导出 PDF 和删除；「最近删除」支持恢复和彻底删除。可用方向键选择、Enter 执行、Esc 关闭并返回原位置，也可用 `Shift+F10` 打开。文字输入和选中文字仍使用系统文本菜单；手机保留长按选择，不显示右键菜单。

桌面版 macOS 的系统菜单栏提供「文件 / 编辑 / 显示 / 窗口 / 帮助」；Windows 隐藏菜单栏，但快捷键仍生效。`⌘ / Ctrl+N` 新建相册，`⌘ / Ctrl+O` 添加照片，`⌘ / Ctrl+Shift+O` 从文件夹导入，`⌘ / Ctrl+Shift+E` 导出 PDF，`⌘ / Ctrl+,` 打开设置。添加照片与导出仅在相册页可用。

按 `?`、桌面版 `⌘ / Ctrl+/`，或在电脑的「设置」里点「键盘快捷键」查看完整列表；输入文字时不会抢占 `?`。授权只读时仍可浏览、下载和更改显示偏好，写入操作不可用；导入或保存期间相关操作暂时停用，未保存的备注仍会要求确认。

## 导出 PDF

电脑端在相册「⋯ → 导出 PDF」打开预览。可选 A4 / Letter 横向、版式（单张 / 宽松 / 紧凑）、标准 / 高画质、封面页和备注图注；视频只导出封面帧，不播放视频。排版复用 3D 相册的分页规则。

桌面版将 PDF 保存到「下载」，完成后可在 Finder / 文件资源管理器中显示；浏览器或源码模式打开系统打印窗口，可选「存储为 PDF」。手机不提供 PDF 导出入口。

## 手机访问

在导航栏点「手机访问」，打开「允许手机访问」，用手机相机扫二维码。手机和电脑要连同一个 Wi‑Fi。每次重新打开开关都会换一个新链接，旧链接失效。

想在 iPhone 上全屏看：用 Safari 打开链接，点分享 →「添加到主屏幕」，以后点主屏幕上的「Folio」图标打开，没有地址栏。用微信扫码时，先点右上角「···」→「在 Safari 中打开」。重新打开开关后，主屏幕上的图标也要删掉重新添加。

第一次启动时，macOS 可能会问是否允许 node 接受传入的网络连接。要选「允许」，否则手机打不开。局域网里走的是 HTTP，只在家里或可信的 Wi‑Fi 下使用。

## 删除

删除的相册、照片和视频先移入相册库内的「最近删除」，保留 30 天。右下角（手机底部）撤销条可在 8 秒内立即撤销；也可从相册墙末尾的「最近删除」卡片进入，选择恢复或彻底删除。彻底删除会再次确认且不能恢复；过期项目在启动及每 6 小时检查时清除。

回收站不计入相册数量和搜索。恢复照片时放回原相册，原相册也已删除时会一并恢复，无法找到原相册时新建同名相册；ID 冲突会重新分配，不覆盖现有文件。备份时先从托盘退出 Folio，等待导入和保存完成，再复制整个相册库文件夹（包括 `.trash`），保留原文件、视频封面、详情和备注。

## 字体与无障碍

英文和数字用 Geist 字体（SIL Open Font License 1.1），打包在软件里，不从网上加载。许可证见 `public/geist-OFL.txt`。

界面采用统一的七档字号与五档圆角，文字最小 12px；3D 与 PDF 的纸面排版单独保留。触控设备上的操作目标至少 44×44px，电脑上至少 24×24px；勾选框可以通过旁边的关联标签扩大点击范围。极宽、极高的照片仍完整显示，必要时在点击区域内留边。

读屏名称包含照片文件名与「封面」状态，看大图的返回按钮说明相册名称或「最近删除」，实际大小按钮包含可见的「1:1」。相册墙按页面标题、相册标题组织层级，便于按标题导航。触控布局通过模拟检查，iPhone 真机和 Windows 手动验收仍需在对应设备上完成。

## 桌面内测开发与分发

已加入 Electron 桌面壳、离线 JSON 授权、托盘和更新协调；当前内测仅支持 Windows 11 x64 与 macOS 13+ Apple Silicon（arm64），Intel Mac 暂不支持。原生打包与技术验证以对应源码的 CI 结果为准；真机与完整发行验收尚未完成，未发布公开更新通道。桌面使用维护者提供的授权公钥；私钥必须保存在仓库外，签发见 `docs/license-issuer.md`。CLI/Vite 保留明确开发模式，不代表桌面应用已获授权。

桌面版的系统标题栏与 Folio 顶栏合成一层：macOS 的红黄绿按钮、Windows 的最小化 / 最大化 / 关闭按钮都在顶栏里，顶栏空白处可以拖动窗口，看大图和 3D 翻阅时也一样。外观（浅色 / 深色 / 自动）同时作用于窗口、标题栏和系统对话框。「设置」里能看到相册库位置和照片数（可在 Finder / 资源管理器中显示，或更换），以及版本和更新状态。窗口会记住大小、位置和是否最大化；上次所在的显示器不在时回到主显示器。

`npm run notices` 生成当前原生目标的第三方清单与声明 ZIP。生成成功不代表已获分发许可；对应源码、LGPL 替换、编解码器及素材权利等仍需审阅。分发门槛和当前限制见 [桌面发行说明](docs/desktop-release.md)。

## 图标

应用图标来自插画源图 `src/assets/folio-app-icon.png`（1024px，圆角方块外透明）：小朋友翻开相册，左页是夕阳海面，右页是远山与河流。页面里的品牌 Logo（顶栏、照片查看页）也使用这张插画；macOS 菜单栏模板和按钮里的小图标仍使用单色矢量 `src/assets/folio-mark.svg`，因为菜单栏图标必须是单色剪影，按钮图标太小、放不下插画细节。修改任一源文件后运行 `npm run icons` 重新生成资源，用 `npm test` 检查格式、尺寸及资源是否同步。插画缩放在 `scripts/icon-raster.js` 中用纯 JavaScript 完成，保证 macOS 与 Windows 生成的文件逐字节一致；同步检查逐字节比较，不要改成 sharp 缩放。
